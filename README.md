# The two things that could end us

Working repo for a Substack series by Jan-Erik Vinje on AI extinction risk: a hub op-ed plus standalone deep-dive spokes.

- `posts/00-two-things.md` — the hub: *Two things a machine would need to end us, and how close we are to both*
- `posts/NN-*.md` — spokes (to come)
- `posts/nb/` — parallel Norwegian (bokmål) versions; same number prefix as the English file. Keep in sync: any change to an English post is mirrored here.
- `plan/series-plan.md` — structure, voice rules, spoke list, release order
- `sources/sources.md` — source register; every factual claim in a post carries an `[Sx]` tag pointing here, with verification status

Before publishing a post: every `[Sx]` it uses must be **verified**, and the tags are stripped.
